# 📚 Arı Kitab | Book Store Website

## 🇹🇷 Türkçe

### Proje Hakkında

Arı Kitab, kullanıcıların kitapları inceleyebileceği ve satın alma deneyimi yaşayabileceği bir kitap satış web sitesi projesidir. Proje, kullanıcı dostu bir arayüz ve kolay bir alışveriş deneyimi sunmayı amaçlamaktadır.

### 🎯 Projenin Amacı

* Kitapları çevrimiçi ortamda sergilemek
* Kullanıcı dostu bir alışveriş deneyimi sunmak
* Web geliştirme becerilerini gerçek bir proje üzerinde uygulamak

---

## 🇬🇧 English

### About the Project

Arı Kitab is an online bookstore website project where users can explore books and enjoy a convenient shopping experience. The project aims to provide a user-friendly interface and an accessible online book shopping experience.

### 🎯 Project Goals

* Display books online
* Provide a user-friendly shopping experience
* Apply web development skills in a practical project
